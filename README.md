# Точка кофе

Учебный сайт вымышленной кофейни. Продолжение ЛР4 в рамках ЛР5 по информатике: работа с Git, ветками и GitHub Pages.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

## Возможности

Сайт содержит сведения о кофейне, меню, преимущества, акции и контакты. Кнопки категорий фильтруют меню. Без JavaScript всё меню остаётся видимым. Три фотореалистичных изображения созданы ImageGen и хранятся локально. Заведение, цены и контакты вымышлены.

## Файлы

- `index.html` — структура.
- `style.css` — оформление и адаптивность.
- `main.js` — доступная фильтрация меню.
- `assets/images/` — фотографии главного экрана, капучино и выпечки.
- `exercises/` — файлы TXT, Python и PNG для общих упражнений.

## История Git

- `main` — объединённый результат.
- `feature/photos` — добавление трёх изображений.
- `feature/menu-filter` — фильтры меню.
- `exercise/materials` — учебные материалы разных форматов.
- Тег `lr4-original` — исходный сайт до доработки.

Три ветки объединены с main отдельными merge-коммитами `--no-ff`. Стили вынесены в отдельный файл непосредственным коммитом в main.

## Публикация

Сайт подготовлен для GitHub Pages: источник `main`, папка `/ (root)`. В корне находятся `index.html` и `.nojekyll`. Планируемый адрес после публикации: https://qq666avesatan.github.io/tochka-coffee-lr5/.
