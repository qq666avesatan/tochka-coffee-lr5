Учебные упражнения ЛР5

git init — создание репозитория.
git add — подготовка изменений.
git commit — запись изменений в локальную историю.
git switch -c — создание ветки и переход в неё.
git merge --no-ff — объединение с отдельным merge-коммитом.
git push — отправка на удалённый сервер.
Fork создаётся на GitHub; локальное клонирование не является форком.
